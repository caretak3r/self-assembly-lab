## How digests work

See [CONTRIBUTING.md](https://github.com/caretak3r/self-assembly-lab/blob/main/CONTRIBUTING.md) for the workflow:

1. Add a new MDX file under `content/latest/` named `YYYY-MM-DD.mdx`.
2. Register it in `content/latest/_meta.js`.
3. Cite real DOIs/arXiv IDs only — never invent papers.
4. Keep the honest framing callout.

<Callout type="warning">
Even the newest papers mostly demonstrate **lab-scale** capabilities. Macroscopic programmable matter, clinical molecular robots, and cheap classroom DNA origami remain limited.
</Callout>
